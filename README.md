# Maintenance Portal

A role-based web application built with ASP.NET to streamline maintenance 
request management and resource allocation.

## Features
- Role-based access: Admin, User, Support Team
- Maintenance request tracking
- Resource allocation
- Status reporting dashboard
- Secure authentication

## Tech Stack
- Backend: ASP.NET (C#)
- Database: SQL Server
- Frontend: HTML, CSS, JavaScript

## Roles
| Role | Access |
|------|--------|
| Admin | Full CRUD, user management, reports |
| User | Raise requests, track status |
| Support Team | View assigned requests, update status |

## Setup
1. Clone the repo
2. Open in Visual Studio
3. Configure SQL Server connection string
4. Run migrations / import database
5. Build and run
